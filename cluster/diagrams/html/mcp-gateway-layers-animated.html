What the MCP gateway is — one layer at a time

One proxy. Everything else either configures it or answers its questions. Colours show who ships each piece.

Envoy — from OpenShift Gateway API — Kubernetes standard Red Hat Connectivity Link — policies, Authorino, Limitador, MCP router/broker/controller, registrations Red Hat build of Keycloak Red Hat OpenShift AI — MCPServer Yours — agents and MCP servers

One proxy. Envoy carries every call. Gateway API and Connectivity Link policies configure it; Authorino and Limitador answer its questions; the MCP router, broker and controller teach it MCP. Nothing else moves traffic.
